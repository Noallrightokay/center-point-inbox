# RATA: deploy guide (retired)

This guide is retired. **[`LAUNCH.md`](LAUNCH.md) is the runbook** for
setting up and deploying the website: the database, the licence key,
Stripe, the environment variables, the deploy itself and the checks after
it.

This file used to describe a browser version of RATA that linked mailboxes
and read mail on the server, with variables and prices that no longer
exist. None of that is true now: mail is read only in the desktop app, and
the website sells licences and runs the AI relay. The old text is in the
git history if you need it; do not follow it. The file stays so that old
links still land somewhere.
